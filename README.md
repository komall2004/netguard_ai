# NetGuard AI

NetGuard AI is an AI-powered network intrusion detection system built using unsupervised machine learning algorithms.

## Features

- Dataset upload
- Dataset analysis
- Data preprocessing
- Threat detection
- Performance evaluation
- Interactive Streamlit dashboard

## Models

- Isolation Forest
- Local Outlier Factor (LOF)
- One-Class SVM

## Technologies

- Python
- Streamlit
- NumPy
- Pandas
- Scikit-learn
